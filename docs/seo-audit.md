# SEO audit — colorbase.in (Phase 0)

Audited 2026-11-21 against a local production build (`next build` + `next start`) of the working tree. Every value comes from the **raw server HTML** (no JavaScript executed), which is what a crawler gets on first fetch. Re-run with:

```bash
npm run build && npx next start -p 3123
node scripts/seo-audit.mjs --base-url http://localhost:3123 --sitemap-sample 200 --out docs/seo-audit.md
```

## Stack
| | |
|---|---|
| Framework | Next.js 15.5 (App Router), React 19, TypeScript, Tailwind CSS 4 |
| Rendering | Server Components. Static (SSG) for most tools and hubs; on-demand ISR (`dynamicParams = true`) for `/color/[hex]`, `/brands/[slug]`, `/brands/[slug]/[hex]`, `/gradient-library/[slug]`, `/interior-colors/[slug]`. Tool widgets are client components inside server-rendered shells. **Not an SPA**, so no pre-render decision is needed. |
| Hosting | Hostinger Node.js web app, `output: "standalone"` + `scripts/hostinger-postbuild.js`; `vercel.json` is an unused stub. |
| Data | Postgres (`pg`) for user data, admin interior palettes and AI; content data lives in `src/lib/data/*`. |
| Existing SEO plumbing | `src/lib/seo.ts` (`createPageMetadata`, JSON-LD helpers, `TARGET_PAGE_SEO`), `src/lib/sitemaps.ts`, `src/app/sitemap.xml/route.ts`, `src/app/robots.txt/route.ts`, `src/app/llms.txt/route.ts`, `/markdown` agent view, `src/middleware.ts` (trailing-slash + catalog 308/404), `src/lib/hex-indexing.ts` (curated HEX index set). |

## Route inventory
- **147 static routes + 18 dynamic templates** (`src/app/**/page.tsx`, excluding `/admin` and `/api`). The full list with per-route data is in the table below.
- `/sitemap.xml` is one flat urlset with **16,099 URLs**: brands 6,787 (incl. brand-HEX pages), `/color/[hex]` ~3,500, gradients ~1,860, color names, palettes, libraries, tools and blog.
- **Full sitemap crawl (all 16,099 URLs):** 0 non-200, 0 redirects, 1 soft 404 (`/color-palette-generator`), 3 duplicate titles, **12,187 URLs with metadata streamed into `<body>`** (see P1).

## Already in good shape
- All pages are server-rendered: H1, intro, guide and FAQ text are in the HTML; tool widgets hydrate on top.
- `robots.txt` already lists GPTBot, ChatGPT-User, ClaudeBot, Claude-User, Google-Extended, PerplexityBot and Applebot-Extended, disallows `/api/`, `/admin/` and `/search?`, and has a Sitemap line.
- Canonicals exist on every page. Trailing slashes 308 to the no-slash form. HEX normalization works: `/color/FF5733` → `/color/ff5733`, `/color/f53` → `/color/ff5533`, `/color/%23ff5733` → `/color/ff5733`.
- 17 of 18 invalid-slug probes return a real 404.
- JSON-LD in use: Organization, WebSite, FAQPage, BreadcrumbList, SoftwareApplication, BlogPosting, ItemList, CollectionPage, WebPage, ImageObject. No invalid blocks.
- OG and Twitter tags on every page; OG image routes exist for color, brand and palette pages.
- No `meta keywords` tag is emitted. The `keywords` field is passed around in code but not rendered.
- `/llms.txt` and the `/markdown` alternate already exist.
- Homepage H2s are already descriptive ("Pick Colors from Images", "Color Palette Generator & Library").

## Prioritized problems
