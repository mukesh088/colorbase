# Content Improvement Plan (Wave 1)

Maps the 15 editorial topics from the AdSense/SEO quality brief to existing ColorBase posts. Prefer reuse and improvement before publishing net-new articles. Two original case-study guides shipped in this wave.

## Priority rule

1. Improve an existing guide if the topic already has a post.
2. Ship a new guide only when the gap is product-critical (workflows, measured demos).
3. Do not invent client logos, traffic numbers, or “approved by Google” claims.
